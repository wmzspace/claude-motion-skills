# 卡点快剪动效视频

用一个 HTML 页面（Canvas 2D，画面是时间 t 的纯函数）+ Playwright 逐帧截图 + ffmpeg 合成，做 10–30 秒的快剪动效片。本 skill 自带引擎、20 多个参数化镜头技法、渲染/合成脚本和配乐合成库，**主题、文案、配色、分镜每次按需求重新设计**。

## 文件

| 路径 | 作用 |
|---|---|
| `assets/template/engine.js` | 引擎：缓动、文字、镜头技法 `FX.*`、镜头冲击、HUD、运动模糊、辉光/色散/闪白后期 |
| `assets/template/index.html` | 18 秒技法演示片，也是新工程的起点（配置 → 镜头函数 → 镜头表/重击表） |
| `assets/template/audio.py` | 与演示片对齐的配乐示例 |
| `scripts/render.mjs` | Playwright 渲染：`info` / `stills` / `frames` |
| `scripts/build.py` | 抽帧联系表、并行渲染（可续渲）、配乐、编码、成片联系表 |
| `scripts/audio_lib.py` | numpy 合成器：pad / kick / snare / hat / bass / bell / boom / riser / whoosh / tick |
| `references/fx-api.md` | 全部 `FX.*` 与文字/图元函数的参数说明 —— **写镜头前先读** |

## 流程

### 1. 明确内容（缺什么问什么，问一次）
主题与用途、时长（默认 20 秒）、要出现的文案/数字/名称、品牌色或 logo、画幅（默认 1920×1080）。信息够就直接做，不要反复确认。

### 2. 先写分镜表，再写代码
判断标准：**任意暂停一帧都像一张海报，任意一秒都有新东西发生。** 如果分镜里出现"卡片网格 + 标题 + 正文 + 淡入淡出"，那是幻灯片，推翻重来。

- **节拍网格**：定 BPM（默认 120，一拍 0.5s）。所有切点、砸字、重击都落在拍点上。每 1 秒至少换一个镜头；高潮段 0.25 秒一切（频闪）；开头 0.5 秒内必须有第一个冲击。
- **结构**（按时长缩放）：开场冲击 → 亮名字/主题 → 3–5 个卖点或章节（每个一秒、每个一种技法）→ 一段频闪或清单把节奏推到最高 → 2–3 个价值词/关键数字 → 标志定格 + 行动号召 → 干脆收尾。
- **每个镜头换一种技法**，相邻镜头换底色（深 / 浅 / 强调色轮换）。技法清单见 `references/fx-api.md`。
- **动作表达词义**：技法要和这一秒的内容有关（"快"用速度线甩入，"稳"用落地压扁 + 砌墙，"准"用描边收拢 + 参考线对齐，"连接"用节点网络）。
- **文案极少、字极大**：主文字 300–620px、最粗字重；每个镜头最多一句副文案（≥40px）；HUD 小字只做装饰。
- **配色克制**：深底 + 浅底 + 一个强调色，外加强调色的明暗变体。在 `KCONF.palette` 里改，镜头里只用 `PAL.*`。
- **首尾呼应**：以一个点/一束光开始，以同一元素收尾。
- 用户没给 logo 时用 `FX.star` 占位或直接用文字标；有 logo 就用 Canvas 路径画出来，并交给 `FX.sample` 做粒子聚合。**不要仿冒真实品牌的标志或页面。**

### 3. 建工程并写镜头
```bash
cp -r <skill>/assets/template <工程目录>     # 得到 engine.js / index.html / audio.py
```
改 `index.html`：
1. `window.KCONF`：尺寸、帧率、`palette`、`fonts`（先 `fc-list | grep -iE "Noto|CJK|Mono"` 确认字体存在且有粗字重）。
2. 每个镜头一个函数 `(g, t, u) => {...}`：`t` 绝对秒，`u` 镜头内秒。**只能依赖 t/u**——不用 `Date.now()`、`Math.random()`（用 `rng(seed)`）、CSS 动画或任何跨帧状态，否则无法分段并行渲染。
3. `K.start({duration, hud:{title}, shots:[[起,止,函数,{label,hud,bloom}]...], hits:[[时间,强度,震屏px]...]})`。
   - `bloom`：深底 0.5–0.6，强调色底 0.12–0.14，浅底 0.07–0.1。
   - `hud`：HUD 颜色，深底用 `PAL.paper`，浅底用 `PAL.ink`，上下不同底色时传 `[上,下]`，可传函数，`false` 关闭。
   - `hits`：每个切点一条（强度 1）；半拍小切 0.5–0.6；全片最重的 1–2 个镜头 1.3–1.4 并加 12–26px 震屏。引擎据此自动加镜头推进、色散、闪白、辉光脉冲。
4. 重击必须落在切点那一帧：下落/砸入类动作让"落地瞬间 = 镜头起点"，之后只做回弹（`FX.slam`）。入场用 `ex`（急停）或 `spr`（回弹），蓄力/吸走用 `ei`。

### 4. 抽帧预检（必须，全片渲染前）
```bash
python3 <skill>/scripts/build.py <工程目录> stills          # 每个镜头自动取 2 个时刻，拼成 stills_sheet.jpg
python3 <skill>/scripts/build.py <工程目录> stills 6.6 12.5  # 或指定时刻
```
看联系表，再挑 2–3 张 `stills/NN.png` 看原尺寸。检查：文字出框/重叠、辉光发灰、浅色镜头发脏、相邻镜头是否雷同、每个镜头是否一眼能读懂。改完再抽一次。控制台出现 `PAGEERROR` 说明页面脚本报错。

### 5. 配乐
照 `audio.py` 的写法：每段一个和弦 `pad`，`beat()` 铺鼓和贝斯，**每个切点一个 `boom` + 一个上行的 `bell`**，段落切换前放 `riser`，甩镜放 `whoosh`，打字放 `typing`，频闪段每 0.25 秒一组 kick+snare+bell。时间直接抄镜头表。`build.py` 会自动运行它。

### 6. 全片渲染与编码
```bash
nohup python3 <skill>/scripts/build.py <工程目录> render > <工程目录>/build.log 2>&1 &
# 轮询（单条命令不要超过 10 分钟）：
for i in $(seq 1 55); do grep -qE "video:|failed|missing|Error" <工程目录>/build.log && break; sleep 10; done; tail -5 <工程目录>/build.log
```
- 按 CPU 核数并行，已渲染的帧会跳过，所以中断后重跑同一命令即可续渲；改了某个镜头就删掉对应帧号的 PNG 或加 `--force`。
- 速度约 0.6–1.5 秒/帧（代码墙、点阵球这类镜头最慢）；20 秒成片在 2 核机器上约 10–15 分钟。
- 输出 `out.mp4` + `qa_sheet.jpg`（每半秒一帧）。默认把文件压到 28MB 以内（`--max-mb`）；`--grain 0` 关颗粒；`--range A B` 只出某段帧；只改了配乐用 `encode` 模式重新合成。

### 7. 检查并交付
看 `qa_sheet.jpg` 和 ffprobe 输出（时长、帧数、有无音轨），然后发送 MP4，附逐秒镜头表。**如实说明**：画面抽帧检查过；配乐是代码合成的、无法试听，听感需要对方确认；若为控制体积降了码率也说明。

## 常见问题

- **整体"不够炫"**：通常是镜头太长、字太小、技法重复、切点没有重击。先查分镜表，不要靠堆后期特效补救。
- **快速运动出现条纹**：给该镜头加 `samples: 24`（或函数 `t => ...` 只在高速段提高）。
- **深色镜头发灰/文字发糊**：降低该镜头 `bloom`。**浅色镜头四角发脏**：`bloom` 设到 0.2 以下，引擎会自动减弱暗角。
- **镜头缩放或震屏露出黑边**：底色用 `fillAll`，自绘背景要多画出画面 200px 以上。
- **文件太大**：颗粒和高速粒子最吃码率，降 `--grain` 或 `--max-mb`。
- **不要边截图边把帧管道给 x264**（会抢 CPU，慢数倍）；`build.py` 已是先落盘再编码。
- **不要用 `pkill -f render.mjs`**（可能杀掉当前 shell）；用 `pgrep -fa node` 找到 PID 再 `kill`。
- **竖版 / 其他画幅**：改 `KCONF.W/H` 即可渲染，但技法的默认坐标按 1920×1080 调过，需通过各自的 `cx/cy/size` 参数重新排版并抽帧确认。
- `shadowBlur`、大字号 `strokeText`、全屏渐变都很慢，每个镜头只用在一两个元素上。
