# 从题材长出镜头：母题方法

套模版的视频有一个共同特征：**把文案换成另一个题材，画面照样成立。** 本文件说明怎么避免这一点。

## 1. 写母题清单（动手前必须完成）

在工程目录写 `storyboard.md`，第一部分是母题清单：这个题材**自己独有**的 8–12 个视觉元素。按下面几类去想，每类至少一个：

| 类别 | 问自己 | 例：电子类大学 | 例：精品咖啡品牌 | 例：医院/医疗 |
|---|---|---|---|---|
| 器物与仪器 | 这行的人每天摸什么、看什么 | 示波器、万用表、电烙铁 | 磨豆机、手冲壶、温度计 | 心电监护、听诊器、显微镜 |
| 材料与纹理 | 它是什么做的，近看是什么样 | 晶圆、PCB 走线、焊点 | 咖啡粉颗粒、油脂、牛皮纸 | 细胞、药片铝箔、纱布纹理 |
| 符号与记号 | 行内特有的标记、单位、代码 | 电路符号、Verilog、摩尔斯码 | 烘焙曲线、风味轮、产地坐标 | 心电波形、处方签、十字 |
| 界面与图表 | 行内人看的屏幕长什么样 | 频谱仪、逻辑分析仪 | 萃取计时器、TDS 读数 | 监护仪数字、CT 切片 |
| 地点与历史 | 在哪里、从哪里来、有什么旧物 | 老校名、建校年份、校区地图 | 产区海拔、港口、麻袋印字 | 院史、门诊楼、老病历 |
| 动作与过程 | 这行最有代表性的一个动作 | 布线、焊接、点亮 | 注水、萃取、拉花 | 听诊、扫描、缝合 |

从清单里挑出 **一条主线母题**（全片反复出现、首尾呼应的那个元素，比如"一条信号"），其余做镜头素材。

## 2. 分镜表：每个镜头都要写清"从哪个母题长出来"

```
| 时间 | 画面 | 来自哪个母题 | 技法（新写 / 改造的 FX.x） | 文案 | 怎么接到下一镜 |
```

规则：
- **至少一半镜头的技法是为这个题材新写的**（示波器、布线、拉花、心电……），用 `drawOn / noise1 / stg / cjk / word / FX.sample` 等零件拼。
- 复用的 `FX.*` 每个最多一次，并且要改造成题材的样子（例如 `FX.network` 的节点换成城市坐标、`FX.isoBars` 的柱子换成晶圆上的 die）。
- **不要照搬演示片的顺序**（砸字 → 甩入 → 字标 → 滚动字幕 → 代码墙 → 网络 → 隧道 → 点阵球 → 柱阵 → 频闪 → 清单 → 轨道 → 描边 → 砌墙 → 滚动带 → 粒子收尾）。
- **转场优先用母题做"匹配剪辑"**：上一镜的波形变成下一镜的走线，走线汇成芯片，芯片的反光变成下一镜的光斑。比纯闪白更高级。
- 开场和收尾必须是题材专属的画面。标志：有官方标志并获准使用时，用 Canvas 路径画出来交给 `FX.sample`；否则用题材名称的文字标。**`FX.star` 是 Claude 标志的近似形状，只在介绍 Claude 时使用。**

## 3. 除了画面，其他维度也不能套

| 维度 | 容易套的默认 | 怎么避免 |
|---|---|---|
| 配乐 | 120 BPM、D 大调、pad + bell + kick | 按 brief 选风格/BPM/调式/音色，`chord()` `scale()` `pluck` `lead` `vinyl` `beat(pattern, swing)` |
| 配色 | 墨黑 + 象牙白 + 陶土橙 | 从题材实物和 brief 的配色策略取 |
| 字体 | 衬线粗体大字 + 等宽小字 | 按 brief 的字体性格选，`fc-list` 里找替代 |
| 后期 | 每个切点闪白 + 色散 + 推镜 | 按 brief 的后期质感调 `caBase/caHit/flash/punch/vignette`、`--grain` |
| 装饰层 | 四角取景框 + 时间码 + 进度刻度 | HUD 默认关闭；按 brief 选装饰层，或做题材专属的装饰（刻度、页码、坐标） |
| 运镜 | 只有推镜冲击 | 选一种运镜语法贯穿全片（推进穿越、横移、俯冲、分屏……） |
| 转场 | 只有闪白硬切 | 母题匹配剪辑、遮罩、穿越、溶解等，按 brief 统一而有变化 |
| 文案 | 一个词一镜 + 一句副文案 | 按 brief 的语气写，用题材自己的说法 |
| 开场 / 收尾 | 光线汇聚开场、粒子标志 + 关机线收尾 | 按 brief 选，和主线母题首尾呼应 |

## 4. 换皮测试（写完分镜、抽帧后各做一次）

对每个镜头问：把文案换成另一个题材（比如把"电子科技大学"换成"某咖啡品牌"），这个画面还成立吗？

- 成立 → 这个镜头是通用模版，回去换成母题画面。
- 全片超过三分之一的镜头"成立" → 不合格，重做分镜。

交付时在说明里列出：哪些镜头是新写技法、哪些复用了 `FX.*`、换皮测试的结果。

## 5. 新写技法的写法

一个技法就是一个纯函数 `(g, u, opts)`：只依赖时间 `u` 和参数，随机数用 `rng(seed)` 在顶层预生成。下面两个是按这个方法写的例子（已实际渲染验证），用来示范"从母题写画法"的思路，**不是让你照抄**——换个题材就该写别的东西。

```js
/* ① 示波器：平直扫描线起振，波形随节拍变形（母题：信号）
   用法：scope(g,u,{amp:lp(0,220,ex(P(u,.4,.6))), draw:ex(P(u,0,.4))}) */
function scope(g,u,o={}){const x0=o.x0??160,x1=o.x1??W-160,cy=o.cy??CY,col=o.col||PAL.accent,amp=o.amp??0;
  g.save();g.strokeStyle=rgb(PAL.paper,.12);g.lineWidth=1;
  for(let x=x0;x<=x1;x+=(x1-x0)/10){g.beginPath();g.moveTo(x,cy-300);g.lineTo(x,cy+300);g.stroke()}
  for(let y=-300;y<=300;y+=60){g.beginPath();g.moveTo(x0,cy+y);g.lineTo(x1,cy+y);g.stroke()}g.restore();
  const pts=[];for(let k=0;k<=400;k++){const f=k/400,x=lp(x0,x1,f),env=Math.exp(-Math.pow((f-.5)*2.2,2));
    pts.push([x,cy+amp*env*(Math.sin(f*40+u*18)*.7+noise1(f*30+u*6)*.3)])}
  for(const[lw,al]of[[14,.12],[6,.3],[2.5,1]])drawOn(g,pts,o.draw??1,col,lw,al);}   // 三层描边 = 荧光余辉

/* ② 自动布线：走线从两侧沿 90°/45° 折线汇向中心，到达后焊盘弹出（母题：电路板） */
const ROUTES=(()=>{const r=rng(9),out=[];for(let i=0;i<28;i++){const dir=i%2?1:-1,sx=dir<0?-40:W+40,sy=80+r()*(H-160),
  tx=CX+dir*(150+r()*130),ty=CY-150+r()*300,dy=Math.abs(ty-sy),mx=tx+dir*(dy+40+r()*160);
  out.push([[sx,sy],[mx,sy],[mx-dir*dy,ty],[tx,ty]])}return out})();
function pcb(g,u,o={}){const col=o.col||PAL.accent;ROUTES.forEach((pts,i)=>{const p=stg(u,i,.025,.7,eio),h=drawOn(g,pts,p,col,3,.85);
  if(p>=1){const a=stg(u-.7,i,.025,.3,spr);g.fillStyle=rgb(o.pad||PAL.accentHi);g.beginPath();g.arc(h[0],h[1],9*a,0,TAU);g.fill()}})}
```

再举几个"从母题写画法"的方向（按题材自己想，不限于这些）：

| 母题 | 可以写成的画法 |
|---|---|
| 摩尔斯电报 / 打字纸带 | 点划按节拍出现，纸带横移，解码出的字逐个打印 |
| 晶圆 / 芯片版图 | 圆形网格逐格点亮，镜头推进到一格，切到版图走线 |
| 频谱仪 | 竖条随 `noise1` 跳动，峰值处弹出标签 |
| 拉花 / 液体 | 用 `noise1` 扰动的同心曲线被拖拽成心形 |
| 心电图 | `drawOn` 画心电波形，波峰处切镜 |
| 地图 / 航线 | 经纬网 + 弧线航线 `drawOn`，城市点用 `stg` 依次亮起 |
| 印章 / 书法 | 用 `layer()` 做遮罩，笔画按顺序擦出 |
| 胶片 / 老照片 | 齿孔条滚动 + 颗粒 + 漏光的 `blobs` |

写完一个新技法先单独抽 2–3 帧看效果，再接进分镜。
